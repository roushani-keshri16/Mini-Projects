# 🌦️ Ultimate Weather App

A modern and interactive weather application built using **HTML, CSS, and JavaScript** that provides real-time weather updates, forecasts, charts, and map visualization.

---

## 🚀 Features

✨ Real-time weather data  
📍 Search weather by city  
📌 Get current location weather  
🌡️ Temperature, humidity & wind details  
📅 5-day weather forecast  
⏱️ Hourly temperature chart  
🌧️ Rain effect (when raining)  
🌍 Interactive map using Leaflet  
📊 Monthly rainfall chart  
🌙 Dark mode toggle  
🕒 Live time and date display  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- OpenWeatherMap API  
- Chart.js  
- Leaflet.js  
- Font Awesome

## 🔑 API Setup

1. Go to https://openweathermap.org/  
2. Create a free account  
3. Generate your API key  
4. Replace this line in `script.js`:

```js
const apiKey = "YOUR_API_KEY_HERE";
```

---

## ▶️ How to Run

1. Download or clone the project  
2. Open `index.html` in your browser  
3. Enter a city name and press **Enter** or click 🔍  
4. Or use 📍 button for current location  

---

## ⚠️ Notes

- Location feature requires browser permission  
- Internet connection is required  
- API has request limits (free tier)
