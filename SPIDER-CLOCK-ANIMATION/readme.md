# 🕷️ Spider Clock Animation

A creative and interactive **Spider Clock Animation** built using **HTML, CSS, JavaScript, SVG, and GSAP**.

This project displays a real-time analog clock where a spider acts as the clock hands while rotating gears create a smooth mechanical animation.

## ✨ Features

- 🕒 Real-Time Analog Clock
- 🕷️ Spider-Inspired Clock Design
- ⚙️ Smooth Gear Animation
- 🎨 SVG Graphics
- 🚀 GSAP Animations
- 📱 Responsive Design
- 🌙 Modern UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- SVG
- GSAP
